# TV Sales — самый простой запуск через GitHub

## Что сделать один раз

1. На GitHub создай новый репозиторий. Назови его `tv-sales`.
2. Выбери **Public** или **Private** — без разницы.
3. Не добавляй README и .gitignore, если загружаешь этот архив целиком.
4. Распакуй архив на компьютере.
5. В репозитории нажми **Add file → Upload files**.
6. Перетащи ВСЁ содержимое этой папки: `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
7. Нажми **Commit changes**.

## Как получить APK

1. Открой вкладку **Actions**.
2. Выбери `Build TV Sales APK`.
3. Дождись зелёной галочки.
4. Открой выполненный запуск.
5. Внизу страницы найди раздел **Artifacts**.
6. Скачай `tv-sales-debug-apk`.
7. Распакуй скачанный ZIP.
8. Установи файл `app-debug.apk` на телефон.

## Если Actions не запустился

Открой Actions, выбери `Build TV Sales APK` и нажми **Run workflow**.

## Тест в приложении

Во вкладке «Сканировать» введи `TEST385079`, нажми «Найти», укажи серийный номер и продавца, затем подтверди продажу.

## Важно

Каждый раз, когда мы меняем код, нужно заменить соответствующие файлы в GitHub и сделать Commit changes. После этого GitHub снова соберёт новый APK.
